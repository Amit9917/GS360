## 5. Smart Study Plan Engine

### How the AI Creates a Personalized Plan

#### Input Variables (Collected During Onboarding)

| Variable | Options | Weight in Plan |
|----------|---------|----------------|
| **Target Year** | 2026 / 2027 / 2028 | Determines total available months |
| **Daily Hours** | 2-12 hours (slider) | Determines daily content volume |
| **Prep Level** | Beginner / Intermediate / Advanced | Sets starting difficulty |
| **Optional Subject** | PSIR / Geography / History / etc. | Cross-maps GS overlap |
| **Work Status** | Full-time aspirant / Working professional | Adjusts schedule flexibility |
| **Strengths** | Self-rated per subject OR Readiness Test data | Allocates less time here |
| **Weaknesses** | Self-rated per subject OR Readiness Test data | Allocates MORE time here |
| **Previous Attempts** | 0 / 1 / 2 / 3+ | Adjusts approach (repeater strategy) |
| **Schedule Preference** | Morning / Afternoon / Night / Flexible | Sets Command Center timings |

#### Plan Generation Algorithm (Simplified)

```
PLAN GENERATION LOGIC:

STEP 1: CALCULATE AVAILABLE TIME
  Total months = Target exam date - Today
  Total study days = months x 26 (excl. 4 rest days/month)
  Daily hours = Student input
  Total available hours = days x daily_hours

STEP 2: SYLLABUS MAPPING
  Load complete UPSC GS syllabus (4 papers, ~180 topics)
  Tag each topic with:
    - PYQ frequency (HIGH / MED / LOW)
    - Estimated study hours (based on topic complexity)
    - Prerequisite topics (e.g., "Fiscal Policy" needs
      "Money & Banking" first)
    - Cross-map with optional subject (if PSIR, flag
      overlapping GS2/GS4 topics)

STEP 3: PRIORITIZE TOPICS
  Priority score per topic =
    (PYQ_frequency x 0.4) +
    (Student_weakness x 0.3) +
    (Syllabus_weightage x 0.2) +
    (Current_affairs_relevance x 0.1)

  Sort topics by priority score (descending)

STEP 4: PHASE ALLOCATION
  Divide available time into 4 phases:

  Phase 1: FOUNDATION (30% of time)
    - Cover all HIGH-priority topics in weak subjects
    - Cover BASIC concepts in strong subjects
    - Answer writing: 1 per day (introductory difficulty)
    - Focus: Build knowledge base

  Phase 2: INTEGRATION (30% of time)
    - Cover MEDIUM-priority topics
    - Start cross-topic connections
    - Answer writing: 1-2 per day (intermediate difficulty)
    - PYQ practice begins
    - Current affairs integration starts
    - Focus: Apply knowledge

  Phase 3: MASTERY (25% of time)
    - Cover remaining LOW-priority topics
    - Full syllabus revision cycle 1
    - Answer writing: 2 per day (exam-level difficulty)
    - Mock tests begin (sectional)
    - Focus: Exam readiness

  Phase 4: EXAM MODE (15% of time)
    - Full syllabus revision cycle 2
    - Full-length mock tests
    - Answer writing: 2-3 per day (time-pressured)
    - Targeted weak-area drills
    - Focus: Peak performance

STEP 5: DAILY TASK GENERATION
  For each day, the system generates:
    {
      date: "2026-03-22",
      phase: "Foundation",
      topics: [
        {subject: "Economy", topic: "Money & Banking",
         priority: "HIGH", est_hours: 1.5},
        {subject: "Polity", topic: "Fundamental Rights",
         priority: "HIGH", est_hours: 1.0}
      ],
      answer_task: {
        question: "Discuss the role of RBI...",
        topic_link: "Money & Banking",
        difficulty: "Introductory",
        time_limit: 20
      },
      revision: [
        {topic: "Mauryan Admin", studied_on: "2026-03-15",
         recall_type: "Day-7", format: "5 MCQs"}
      ],
      current_affairs: [
        {headline: "RBI holds repo rate at 6.5%",
         gs_paper: "GS3", topic_link: "Monetary Policy"}
      ],
      estimated_time: "3.5 hours"
    }

STEP 6: WEEKLY ADAPTATION
  Every Sunday, the AI reviews the week:
  - Topics completed vs planned
  - Answer scores trend
  - Recall accuracy per topic
  - Time spent vs estimated

  ADJUSTMENTS:
  - If student completed < 70% of planned:
    Reduce next week's volume by 20%
  - If recall accuracy < 50% on any topic:
    Add that topic to revision priority queue
  - If answer scores improved > 10% week-over-week:
    Increase difficulty level
  - If student skipped 2+ days:
    Trigger "Recovery Week" with lighter load
```

## 8. Answer Writing & AI Scoring Flow

### End-to-End Technical Flow

```
ANSWER SCORING PIPELINE

STEP 1: STUDENT SUBMITS ANSWER
  Option A: Handwritten (Primary)
    - Open phone camera via app
    - Guide overlay ensures proper alignment
    - Capture 1-4 pages
    - Auto-crop, enhance contrast, straighten
    - Upload compressed images

  Option B: Typed (Fallback)
    - In-app text editor with word counter
    - Timer running alongside
    - Auto-save every 30 seconds
    - Submit when done

STEP 2: PRE-PROCESSING (5-10 seconds)
  For handwritten:
    - Image enhancement (brightness, contrast)
    - Page order detection
    - Rotation correction
    - OCR via Google Vision API / Azure Read API
    - Text extraction with confidence score
    - If confidence < 70%: flag for manual review
  For typed:
    - Direct text processing

STEP 3: AI ANALYSIS (30-60 seconds)
  Input: Extracted text + Question + Rubric
  
  Analysis modules:
  
  a) STRUCTURE ANALYSIS
     - Detect: Introduction present? (thesis statement?)
     - Detect: Body paragraphs (count, flow)
     - Detect: Conclusion present? (forward-looking?)
     - Score: 0-10

  b) CONTENT ACCURACY
     - Match against: Topic knowledge base
     - Check: Key concepts mentioned?
     - Check: Factual errors? (flag specific lines)
     - Check: Constitutional articles/data cited?
     - Score: 0-10

  c) ANALYTICAL DEPTH
     - Check: Multiple perspectives covered?
     - Check: Cause-effect relationships?
     - Check: Critical evaluation (not just description)?
     - Check: Original insight beyond textbook?
     - Score: 0-10

  d) VALUE ADDITION
     - Detect: Diagrams/flowcharts mentioned?
     - Detect: Data points/statistics cited?
     - Detect: Case studies/examples?
     - Detect: Committee/commission references?
     - Score: 0-10

  e) COMPLIANCE
     - Word count vs limit (250 words typical)
     - Time taken vs limit (20 minutes typical)
     - Score: 0-10

STEP 4: SCORE GENERATION (5 seconds)
  Total = (Structure x 0.20) + (Content x 0.25) +
          (Depth x 0.25) + (Value x 0.20) +
          (Compliance x 0.10)

  Generate: 3 specific improvement suggestions
  Generate: Comparison points with model answer

STEP 5: RESULT DELIVERY (within 2 minutes of submission)
  Student sees:
    - Overall score (e.g., 6.8/10)
    - Dimension-wise breakdown with color coding
    - Specific feedback per dimension
    - Model answer (expandable)
    - Side-by-side comparison highlights
    - 30-day score trend graph
    - "Top 3 things to improve for next answer"

STEP 6: WEEKLY HUMAN REVIEW (Elite plan only)
  One answer per week selected (usually the weakest)
  Assigned to human mentor
  Human reviews:
    - AI score accuracy (validates or adjusts)
    - Writes 3-5 paragraphs of detailed feedback
    - Records 10-15 min video walkthrough
    - Suggests specific practice areas
  Student receives within 48 hours

STEP 7: DATA FEEDBACK LOOP
  - AI scoring compared to human scoring weekly
  - Calibration: If AI and human differ by > 1.5 points
    on any dimension, retrain that scoring module
  - Student scoring patterns added to their profile
    for study plan adaptation
```

## 9. Revision Engine Mechanics

### Spaced Repetition Schedule

```
REVISION CYCLE FOR EACH TOPIC:

Day 0:   Student studies topic (initial learning)
         System records: topic_id, date, comprehension_score

Day 1:   RECALL TEST #1 (Quick)
         Format: 5 MCQs (2 min)
         If score >= 80%: PASS -> schedule Day 7
         If score 50-79%: WARN -> add 1 extra MCQ on Day 3
         If score < 50%: FAIL -> re-study summary + retest Day 2

Day 7:   RECALL TEST #2 (Medium)
         Format: 5 MCQs + 1 short answer (5 min)
         If score >= 70%: PASS -> schedule Day 15
         If score < 70%: FAIL -> re-enter revision at Day 3

Day 15:  RECALL TEST #3 (Deep)
         Format: 5 MCQs + 1 short answer + map/diagram (8 min)
         If score >= 70%: PASS -> schedule Day 30
         If score < 70%: FAIL -> re-enter at Day 7

Day 30:  RECALL TEST #4 (Comprehensive)
         Format: 5 MCQs + 1 full answer writing (15 min)
         If score >= 70%: PASS -> schedule Day 90
         If score < 70%: FAIL -> re-enter at Day 15

Day 90:  RECALL TEST #5 (Retention Confirmation)
         Format: 3 MCQs + 1 one-liner (3 min)
         If score >= 80%: RETAINED -> mark green on dashboard
         If score < 80%: re-enter at Day 30

ADAPTIVE LOGIC:
  - Topics recalled easily -> spacing INCREASES
    (7 -> 15 -> 30 -> 90 -> 180 days)
  - Topics forgotten -> spacing DECREASES
    (back to Day 1 cycle, flagged as "weak")
  - Max 3 revision tests per day
    (to prevent revision fatigue)
  - Sunday: Revision-only day (no new topics)
```

### 23.2 How the Plan Adapts in Real-Time

```

EVERY SUNDAY AT 10 PM, THE AI REVIEWS YOUR WEEK:

INPUT DATA:

  - Answer scores per subject (trending up or down?)
  - Recall accuracy per topic (what are you forgetting?)
  - Time spent vs time allocated
  - Monthly test results
  - Difficulty level performance
  - Engagement patterns (skipping topics? rushing?)

ADAPTATION RULES:

  IF answer_score[Economy] < 50% for 2 consecutive weeks

    -> Add 2 extra Economy sessions next week
    -> Reduce time on strongest subject by 1 session
    -> Schedule Economy PYQ deep-dive
    -> Assign Economy mentor focus for biweekly call
    -> Notification: "We noticed Economy needs attention.
       Next week's plan has more Economy practice."

  IF student scores > 70% on ALL topics in current phase

  THEN:
    -> Move student to next phase EARLY

    -> And slow learners get more foundation time
    -> "Congratulations! You've mastered Phase 1 in
```

## 28. Plan Engineering: Monthly vs Yearly Strategy

### 28.1 The "Upgrade & Save" Philosophy
GS 360 uses a two-step conversion funnel. We use **Monthly plans** to lower the friction of entry and **Yearly plans** to lock in student commitment and normalize cash flow.

| Plan | Monthly Rate | Yearly Rate (Upfront) | One-Time Savings |
|------|--------------|-----------------------|------------------|
| **Core** | Rs 2,499 | Rs 24,999 | Rs 4,989 (2 Months Free) |
| **Pro** | Rs 4,499* | Rs 44,999 | Rs 14,489 (25% Savings) |
| **Elite** | Rs 7,499* | Rs 74,999 | Rs 24,989 (25% Savings) |

### 28.2 The "Kit Fee" Protection
To prevent students from subscribing for one month, receiving the Rs 6,100 Welcome Kit, and then cancelling, we implement a **Kit Fee** for Monthly users.

* **For Core:** No Kit Fee (Digital Only).
* **For Pro/Elite Monthly:**
  * **Month 1 Payment:** Rs 9,999 (Subscription + Rs 5,500 Kit Fee).
  * **Month 2 onwards:** Rs 4,499.
  * *Result:* The student essentially "buys" the books in Month 1.
* **For Pro/Elite Yearly:**
  * Kit Fee is **WAIVED (Rs 0)**.
  * This is our strongest nudge to convert students to the Yearly plan.
